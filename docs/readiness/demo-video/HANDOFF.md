## Audio and rights

The first private preview used native synthesized Samantha speech for local pacing. It is not the public deliverable. Apple's published [macOS Tahoe license, section 2F](https://www.apple.com/legal/sla/docs/macOSTahoe.pdf#page=3) restricts public sharing of System Voice recordings. The public MP4 therefore contains the authored original score and captions only. The original captions are written from the project script, not Apple's Live Captions. The owner can record the supplied script in their own voice. No system-voice recording, stock music, user voice clone, paid service or newly installed third-party tool was published. A clearly named private preview remains only in the owner's local Downloads folder and must not be uploaded.

The compositor uses Apple's [AVAssetWriter pixel buffer API](https://developer.apple.com/documentation/avfoundation/avassetwriterinputpixelbufferadaptor/pixelbufferpool) and native AVFoundation exports. render.swift creates the private pacing preview; mux-public.swift deliberately combines an audio-free picture track with original-score.wav. It rejects an audio-bearing picture source. The public export contains no system speech. Native framework deprecation warnings on macOS 27 are retained; no warning or safety threshold was changed.
