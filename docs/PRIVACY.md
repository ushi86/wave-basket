# Anon-RPC measurement procedure

Status: **Partial**. There is no full Sepolia lifecycle measurement for this increment. The historical worker-only observation in `VERIFICATION.md` measured 4.44s startup and a 33.3% successful-call anonymous share for a tiny probe; it is neither current full-session evidence nor a passing coverage result.

The configured default is immutable Nox `0xDf5Db854BA75B52a4bF1a250a93D8d25cB982b2d`, browser harness 0.4.0. The previously tested immutable default is retained; the engineering brief's mutable alternative has not been verified or silently substituted. The specifier pins worker bytes; pinning does not independently audit those bytes or all network infrastructure.

Use a clean committed build and a genuine Sepolia deployment manifest matching that release. Start a fresh browser session, record browser/version, network, commit, per-component mock modes and actual startup. Through the dashboard perform basket creation, deposit, both flagship hook directions, actual CLI-driven rebalance, settlement exit and in-kind exit. Observe new rebalance history during the session. Keep wallet-side RPC/broadcasts and off-browser CRE distinct from app read counts.

On Privacy, check the private connection, then use **Stop worker and test fail-closed** after completing the lifecycle. The app closes its real worker and attempts a private read. It must error without increasing direct successes. Capture a screenshot showing the failure result and counters. Export session measurement to the displayed `docs/privacy/session-*.json` path. Exporting records observed data; it does not create transactions or certify the session. Reload reconnects privately and starts a new set of counters. The explicit direct-block action authorizes exactly one direct read and changes the badge; do not interpret it as a mode switch.

The JSON includes attempted/successful per-route and per-method calls, failures, startup, worker/harness configuration, actual observed lifecycle transaction hashes, release/dirty state, and fail-closed result. Scope is local, worker-only or partial unless every required action was observed with clean release provenance. Save the downloaded JSON and actual screenshot separately, write the browser/version and observed limitations here, and reference those exact files in `evidence/submission.json`. All canonical hashes are independently checked; local chain 31337 is never Sepolia proof.

Successful coverage is `anon / (anon + bootstrap + direct) * 100`; batch members count individually, failed attempts do not inflate successes. Acceptance requires <10s startup and >=95% successful anonymous coverage. Report actual values even when they fail. Bootstrap uses direct metered RPC; wallet RPC is outside the meter; worker download and static assets are not JSON-RPC reads. No automatic direct fallback is present. Browser exports remain observations requiring review, not signed attestations.
